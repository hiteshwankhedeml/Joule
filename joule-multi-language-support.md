# Joule Multi Language Support

* Supports 12 language apart from English
* Because Joule relies on a Large Language Model, Joule can understand languages other than those officially  &#x20;supported.&#x20;
* If you send a request in a language other than those supported by Joule, it is possible that Joule  \
  will understand the request and provide a response.&#x20;
* However, if Joule is able to understand the request, the  &#x20;response will be provided in the language set by the associated SAP application.
