# Constraints for Analytical Insights

* For analytical support only this languages are supported:
  * English
  * German
  * Italian
  * French
  * Spanish



**Specifying the word "chart":**

* Sometimes Joule may fail to create the chart with the requested analytical information.&#x20;
* If Joule doesn't create  &#x20;a chart from SAP Analytics Cloud (on desktop devices you should see a "Created by SAP Analytics Cloud"  &#x20;watermark), try including words like "chart” or “analytical chart” in your question



**Specifying model name in Question:**

* When Joule can find answers to your question using more than one data model, it will prompt you to specify  &#x20;the data you want to use to create the chart
*   We can select data model here, if that also fails then in the query add the data model also when asking
